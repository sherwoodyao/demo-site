# Analytics Demo

A simple one-page application with four navigation links and Google Analytics integration.

## Features
- Single page application with dynamic content loading
- Four navigation sections: Home, About, Services, and Contact
- Google Analytics integration to track user interactions
- Responsive design for mobile and desktop

## Setup
1. Replace `G-XXXXXXXXXX` in index.html with your actual Google Analytics Measurement ID
2. Deploy to GitHub Pages by pushing to the main/master branch

## GitHub Pages
This site is configured to be hosted on GitHub Pages.
